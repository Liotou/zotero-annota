Each highlight color decides on its own whether it runs automatically or only on request — see Prompt below. Colors with no prompt are never touched. Ticked: the local Claude Code CLI runs each request. Unticked: the Mistral settings below are used. Runs claude -p as a local process — no API key, it uses whatever claude is logged into. Use the ABSOLUTE path (Zotero doesn't see your shell PATH), e.g. /Users/you/.local/bin/claude. Model can be sonnet, opus, or a full id; blank uses the CLI default. Slow (a few seconds' cold start per call), so better suited to the "on request" mode than bulk auto-generation. The Mistral path works with any OpenAI-compatible chat/completions endpoint (get a key at console.mistral.ai). Available in your prompt as {{language}} and {{maxWords}}. They only take effect if your prompt uses them. Helps the model resolve acronyms and vague references. Missing fields are skipped. Long abstracts cost tokens on every highlight — 0 disables truncation. When the highlighted passage cites sources, Annota resolves them to real bibliographic entries and passes them to the AI as {{references}} — so it can name who is being cited instead of guessing. It first follows the PDF's internal links (the same mechanism as Zotero's hover popup, reliable but needs the PDF open in a tab), and otherwise falls back to reading the article's reference list from the PDF text. Nothing is sent when a citation can't be resolved. Each highlight color has its own prompt. The highlighted text is sent to it, and the reply becomes the annotation comment.
