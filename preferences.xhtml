A few seconds of cold start per call, so it suits "on request" better than bulk runs. Everything is configured per highlight color. A color with nothing set is never touched — that's how you keep Annota off your ordinary highlighting. No color is configured yet, so Annota won't do anything. Pick a color above and write a prompt. Leave empty and the comment is simply the AI's reply. Fill it in to compose the comment yourself: {{ai}} is the AI's reply, and any other variable is inserted verbatim — no model involved, so it can't be paraphrased or invented. A line whose variables are all empty is dropped. Example — AI note, then the cited works exactly as found in the PDF: {{ai}} <i>{{references}}</i> Omit {{ai}} entirely and no AI request is made at all: the comment becomes purely deterministic (and needs no API key).
