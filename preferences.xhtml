Every field is also a variable — {{titre}}, {{paraphrase}}… — usable in the prompt and in the layout. 2 When it runs As soon as I create the highlight Only when I ask (right-click → Annota), or when I fill the fields 3 Use the AI optional Leave empty for a fully manual comment. With fields above, the prompt is bound to those fields: the model fills the ones you left empty, and nothing else — what you typed by hand is never rewritten. Fill the whole form and no request is sent at all. Custom layout (rarely needed) With fields declared above, you can ignore this: the comment is one line per field, in order, each in its own format. Fill it in only to depart from that — put fields on the same line, add fixed text, or use {{ai}} to have the model write the whole comment in one go instead of filling the fields one by one. A line whose variables are all empty disappears. Variables you can use Your fields — each one, by name. The passage — {{text}} (highlighted text), {{comment}} (a note already there), {{page}}, {{references}} (works cited inside the passage). The document — {{title}}, {{authors}}, {{year}}, {{publication}}, {{abstract}}. Your settings — {{language}}, {{maxWords}}. Only in the layout: {{ai}}. These names are reserved — a field reusing one is ignored. Ready-made prompts: PROMPT-EXAMPLES.txt on GitHub. Clear this color Only used by colors that call the AI. Chat with the document you're reading, or with your whole library: click the 💬 button in the tab bar, or press ⌘J / Ctrl+J. The panel takes the place of the right-hand pane, in the library and in the PDF reader. Answers cite pages or references, and a click takes you there. A small fast model suits annotations; a chat about a whole article gains from a bigger one (mistral-large-latest, opus, qwen2.5:14b…). Ollama tags matter here too. What the model reads My annotations on the document (highlights and comments) My notes on the reference Context size (characters) 0 = automatic, per provider Library items per answer How the context is built Automatic: about 100,000 characters for an API, 200,000 for the Claude CLI, 12,000 for Ollama and 6,000 for Apple Intelligence, whose windows are small. A document that doesn't fit is cut by pages: the first page, then the pages closest to your question. The answer says how much was sent. With the PDF open in the reader, the text is read page by page with the journal's own page numbers, so “p. 215” is the page printed on the article. Closed, Annota falls back on Zotero's extracted text. Ollama truncates silently beyond its context window: to send more, raise it (OLLAMA_CONTEXT_LENGTH=16384 ollama serve) and set the size above accordingly. My library runs Zotero's own search (all fields, notes, full text) on the words of your question and sends the best matches, with your annotations that mention them. A refused key or a missing model is never retried — the answer would be the same. Good to know There is no master switch: each color decides for itself, and a color with nothing set is never touched.
