================================================================================
ANNOTA — EXAMPLE PROMPTS
================================================================================

Annota ships with NO prompt at all: it stays inert until you configure one.
Prompts are set per highlight color — click a color swatch above the prompt box
in Annota's preferences (Add-ons -> Annota), then paste one of the prompts below.

A color you leave empty is never processed. That is how you keep Annota off the
colors you use for ordinary highlighting.

Each color also has a mode:
  * Automatically      — runs as soon as you create the highlight.
  * Only on request    — nothing happens on highlight; you right-click the item
                         (or reference) -> Annota to run it later. Use this when
                         you want to write your paraphrase by hand first and have
                         the AI only format/title it (see {{comment}} and #11/#12).

Provider: Mistral by default, or tick "Use Claude Code CLI" in preferences to run
the local `claude -p` command instead (uses your Claude subscription, no API key;
set the absolute path to `claude`).


--------------------------------------------------------------------------------
AVAILABLE VARIABLES
--------------------------------------------------------------------------------

  {{text}}         the highlighted text
  {{comment}}      the note already in the annotation (your hand-written
                   paraphrase) — lets the AI format/augment it instead of
                   paraphrasing for you
  {{title}}        title of the source document
  {{authors}}      authors of the source document
  {{year}}         year of the source document
  {{abstract}}     abstract of the source document (truncated per settings)
  {{publication}}  journal / book / proceedings
  {{page}}         page of the highlighted passage
  {{references}}   full bibliographic entries for works cited INSIDE the
                   passage, looked up in the article's own reference list
  {{maxWords}}     the "Word limit" setting
  {{language}}     the "Reply language" setting

Two modes:

  * If your prompt contains NEITHER {{text}} NOR {{comment}}, it is used as
    instructions and the highlighted passage (plus your existing note and the
    document context, if enabled) is appended automatically. This is the usual
    case.

  * If your prompt DOES contain {{text}} or {{comment}}, it is sent exactly as
    written and you control the whole request yourself.


--------------------------------------------------------------------------------
0. ACADEMIC NOTE — FIELD VERSION (recommended)
--------------------------------------------------------------------------------

Same result as #1, but built on FIELDS instead of one free-form answer. Paste
this in the "What goes in the comment" box:

titre      | Titre      | text     | bold
paraphrase | Paraphrase | textarea
reference  | Référence  | text     | italic

...and this in the prompt box:

Tu transformes un passage surligné d'un article académique en une note de
lecture structurée. Réponds en {{language}}.

Le contexte joint (titre, auteurs, année, résumé) décrit l'article que je suis en
train de lire. Il sert à comprendre le passage : ne le cite jamais comme source.

Le bloc « Works cited in the passage » contient les entrées bibliographiques
résolues depuis la bibliographie de l'article. C'est ta seule source pour nommer
les auteurs cités. Il peut être vide, incomplet, ou contenir une entrée sans
rapport : ne t'en sers que pour les appels de citation réellement présents dans
le passage surligné.

CHAMP titre
- 3 à 8 mots. Nomme l'idée centrale du passage surligné.
- Ne recopie pas le titre de l'article : ce n'est pas ce qui est demandé.
- Formulation directe. Pas de sous-titre après deux-points, pas de question,
  pas de formule d'accroche.
- Se termine par un point.

CHAMP paraphrase
- Reformule le passage avec tes propres mots : 2 à 5 phrases,
  {{maxWords}} mots maximum.
- Fidèle au sens, sans ajout d'information, sans jugement, sans reprise
  littérale de plus de quelques mots consécutifs.
- N'y fais figurer aucun appel de citation, ni numéro, ni parenthèse d'auteur :
  les sources vont uniquement dans le champ reference.

CHAMP reference
- Ne le renseigne QUE si le passage surligné contient lui-même un appel de
  citation. Deux formes possibles :
  · nominale — « (Moulin, 1999) », « Moulin et al. (2009) » ;
  · numérique — « [1] », « [2, 5] », « [3-6] ».
  Sinon, laisse-le entièrement vide — pas de parenthèses vides, pas de « aucune ».
- Format attendu : (Auteur et Auteur2, année, p. XX ; Auteur3, année)
- Le résultat est TOUJOURS en auteur-année. Ne laisse jamais un numéro : « [1] »
  doit devenir « (Dyllick et Hockerts, 2002) » en utilisant l'entrée
  correspondante du bloc des références.
- Noms d'auteurs :
  · appel nominal → reproduis les noms tels qu'ils apparaissent dans le passage
    (« Moulin et Jones », « Moulin et al. ») ;
  · appel numérique → prends les noms de famille dans l'entrée résolue :
    un auteur « Dyllick » ; deux auteurs « Dyllick et Hockerts » ;
    trois ou plus « Dyllick et al. ». Jamais les prénoms ni les initiales.
- Sépare les références par « ; », dans leur ordre d'apparition dans le passage.
- Si un appel de citation n'a aucune entrée correspondante, omets-le simplement.
  N'écris jamais « [1] » ni « (auteur inconnu) ». Si aucun appel n'est
  résolvable, laisse le champ vide.
- Numéro de page : ne l'ajoute que s'il figure DANS LE PASSAGE, immédiatement
  après l'année, sous la forme « , p. 93 » ou « , pp. 12-15 ».
  · Conserve la forme (p. / pp. / plage) telle qu'écrite, MAIS écris toujours
    une espace entre « p. » et le chiffre : « p.93 » devient « p. 93 ».
  · Cette page est celle indiquée dans la citation contenue dans le passage.
    N'utilise jamais la page de l'article que je suis en train de lire.
  · N'extrais JAMAIS de numéro de page du bloc des références : la pagination
    qui y figure (« 11(2), 130-141 ») est celle de la revue, pas une page citée.
- N'invente jamais de référence, d'année ni de page.

Aucune balise HTML, aucun Markdown, aucun guillemet autour des valeurs : écris
le texte nu, la mise en forme est appliquée ensuite.

Why this beats #1:
  * The markup is declared once in the fields, not begged for in the prompt —
    the model returns plain text and cannot break the formatting.
  * The reference line disappears on its own when the field comes back empty:
    a line whose variables are all empty is dropped. No more "omit the line".
  * You can fill any field by hand in the selection popup. What you type is
    never rewritten — the model only fills the blanks, and if you fill them all,
    no request is sent at all.
  * No layout needed: one line per field, in the declared order.


--------------------------------------------------------------------------------
1. ACADEMIC NOTE
--------------------------------------------------------------------------------

You turn a highlighted passage from an academic article into a structured
note, ready to paste into a Zotero annotation comment.

Reply EXACTLY in this format, and nothing else:

<b>Title.</b>
Concise paraphrase.
<i>(Author, year, p.XX ; Author2, year)</i>

Strict rules:
- The title is 3 to 8 words, captures the passage's core idea, and ends with
  a period placed INSIDE the <b>…</b> tags.
- The paraphrase restates the passage in your own words: 2 to 5 sentences,
  {{maxWords}} words maximum, faithful to the meaning, adding nothing.
- The reference line appears ONLY if the passage explicitly cites one or more
  sources (author name + year present in the highlighted text).
  Format: <i>(Author, year ; Author2, year)</i>, separator " ; ".
  Include the page number IF it appears in the passage, right after the year
  as ", p.XX" — e.g. (Moulin, 1999, p.93 ; Jacques, 2009).
  Keep page notation as written (p., pp., ranges such as "p.12-15").
  Never add a page number that is not in the passage.
- Never invent a reference, and never cite the source article itself.
- Reply in {{language}}.
- Use ONLY the <b> and <i> tags. No Markdown, no code blocks, no introduction
  or explanation.


--------------------------------------------------------------------------------
2. BRIEF SUMMARY
--------------------------------------------------------------------------------

Summarize the highlighted passage faithfully in {{language}}.
{{maxWords}} words maximum. Return only the summary, with no introduction
and no meta commentary.


--------------------------------------------------------------------------------
3. PLAIN-LANGUAGE EXPLANATION
--------------------------------------------------------------------------------

Explain the highlighted passage in {{language}}, in plain and accessible
language, as if to a non-specialist. {{maxWords}} words maximum.
Get straight to the point, with no introductory sentence.


--------------------------------------------------------------------------------
4. KEY POINTS (BULLETED LIST)
--------------------------------------------------------------------------------

Extract the key points of the highlighted passage as a bulleted list in
{{language}}. One bullet per idea ("- " at the start of the line), concise
wording. No introduction and no conclusion.


--------------------------------------------------------------------------------
5. TRANSLATION
--------------------------------------------------------------------------------

Translate the highlighted passage faithfully into {{language}}.
Return only the translation, with no notes and no commentary.


--------------------------------------------------------------------------------
6. CRITICAL READING  (good candidate for a red highlight)
--------------------------------------------------------------------------------

Assess the highlighted passage critically, in {{language}}, in at most
{{maxWords}} words. Name the claim being made, then the main limitation:
unsupported assertion, ambiguous term, missing evidence, or overreach.
If the passage is sound, say so in one sentence rather than inventing a flaw.
Return only the assessment, with no introduction.


--------------------------------------------------------------------------------
7. DEFINITION OF TERMS  (good candidate for a green highlight)
--------------------------------------------------------------------------------

Define the key technical terms appearing in the highlighted passage, in
{{language}}. One line per term, formatted as "<b>Term</b> — definition".
Define each term as it is used in this specific context, not in general.
If the passage contains no technical term, reply with a single dash.


--------------------------------------------------------------------------------
8. QUESTIONS RAISED  (useful for building a reading agenda)
--------------------------------------------------------------------------------

Based on the highlighted passage, write 2 to 4 questions in {{language}} that
a researcher should investigate next. One question per line, starting with
"- ". Make them specific to this passage, not generic. No introduction.


--------------------------------------------------------------------------------
9. LINK TO THE SOURCE  (uses document metadata)
--------------------------------------------------------------------------------

Summarize the highlighted passage in {{language}}, {{maxWords}} words maximum,
then add a final line citing the source exactly as:
<i>({{authors}}, {{year}}, p.{{page}})</i>
If the author or year is unknown, omit that part rather than guessing.


--------------------------------------------------------------------------------
10. FULL CONTROL  (advanced mode, uses {{text}})
--------------------------------------------------------------------------------

Article: {{title}} ({{authors}}, {{year}})
Abstract: {{abstract}}

Passage highlighted by the reader on page {{page}}:
"""
{{text}}
"""

Explain in {{language}}, in {{maxWords}} words maximum, how this passage
relates to the article's overall argument as described in the abstract.
Return only that explanation.


--------------------------------------------------------------------------------
11. FORMAT MY OWN NOTE  (keeps YOUR paraphrase — best as an "on request" color)
--------------------------------------------------------------------------------

Set this color to "Only on request" in preferences. Highlight a passage, write
your paraphrase by hand in the comment, then right-click the item -> Annota ->
"Regenerate all comments". The AI only formats what you wrote — it does not
paraphrase for you.

You format an existing annotation note without changing its meaning.
Keep the wording and ideas of the note; only improve structure and add a title.

Reply EXACTLY in this format, and nothing else:

<b>Title.</b>
{{comment}}
<i>(Author, year, p.XX ; Author2, year)</i>

Rules:
- The title is 3 to 8 words, names the central idea of the note, direct and
  simple, ending with a period inside the <b>…</b> tags.
- Keep the note ({{comment}}) as its core. Do not rewrite it, do not summarize
  it, do not add information. Fix only obvious typos and spacing.
- Add the reference line ONLY if the highlighted passage below cites sources
  (author + year). Read them from the passage, never from the article you are
  reading. Include a page number only if it appears in the passage, as ", p.XX".
- Reply in {{language}}.
- Use ONLY the <b> and <i> tags. No Markdown, no code block, no preamble.

Highlighted passage (source for citations only):
"""
{{text}}
"""


--------------------------------------------------------------------------------
12. TITLE + CITED AUTHORS ONLY  (paraphrase untouched)
--------------------------------------------------------------------------------

Same idea as #11 but minimal: prepend a short bold title to the user's note and,
if the passage cites sources, append them — nothing else changes.

Return, with no other text:
Line 1: <b>Title.</b>  (3–8 words naming the idea of the note below)
Line 2: the note, copied verbatim: {{comment}}
Line 3, ONLY if the passage cites sources: <i>(Author, year ; …)</i> built from
citations found in the passage below (with page numbers if present, as ", p.XX").

Reply in {{language}}. Only <b> and <i> tags. Never alter the note's wording.

Passage (citation source only):
"""
{{text}}
"""


--------------------------------------------------------------------------------
13. NAME THE WORKS CITED IN THE PASSAGE  (uses {{references}})
--------------------------------------------------------------------------------

When the passage cites sources as [1], [2] or (Author, year), Annota resolves
them against the article's own reference list and hands you the real entries.
This lets the note say WHO is being cited instead of copying a bare number.

You turn a highlighted passage into a structured note for a Zotero annotation.

Reply EXACTLY in this format, and nothing else:

<b>Title.</b>
Concise paraphrase.
<i>(Author, year ; Author2, year)</i>

Rules:
- Title: 3 to 8 words, direct and simple, naming the passage's central idea,
  ending with a period inside the <b>…</b> tags.
- Paraphrase: 2 to 5 sentences, {{maxWords}} words max, faithful, no additions.
- Reference line: include it ONLY if the passage cites sources. Build it from
  the resolved entries below — use the real author surnames and years, never a
  bare "[1]". Keep the passage's page numbers if it gives any (", p. 93").
  If an entry below has no match in the passage, ignore it.
- Never invent a reference, and never cite the article being read itself.
- Reply in {{language}}. Only <b> and <i> tags, no Markdown, no preamble.

Works cited in this passage, resolved from the article's bibliography:
{{references}}
